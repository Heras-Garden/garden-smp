# Third-party font notes

The Garden SMP includes redistributable font alternatives and credits the projects that inspired the requested font directions.

- `garden:medieval` uses Cinzel Decorative, distributed under its upstream open-font terms. Style reference: Ashen 16x Custom Font — https://www.curseforge.com/minecraft/texture-packs/ashen-16x-custom-font
- `garden:storybook` uses EB Garamond, distributed under its upstream open-font terms. Style reference: Souls RPG Font — https://www.curseforge.com/minecraft/texture-packs/souls-font
- Alagard reference requested by the server owner: https://www.curseforge.com/minecraft/texture-packs/alagard-font . The All Rights Reserved Minecraft pack implementation is not redistributed here.
- `garden:smooth` uses Intel Clear Sans under its upstream Apache 2.0 terms. Style reference: Der's Smooth Shaded Font — https://www.curseforge.com/minecraft/texture-packs/smooth-shaded-font

The linked third-party Minecraft packs remain the work of their respective authors. No Ashen or Frozy Alagard resource-pack files are bundled in this pack.
