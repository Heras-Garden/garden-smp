# The Garden SMP Resource Pack

`HerasGardenRP.zip` is the deployable Garden SMP resource pack. It is maintained directly and does **not** require GitHub Actions to build.

## Vanilla animals

Custom passive/neutral animal textures, random-mob variants, saddles, and rabbit CEM models have been removed from the deployable pack. Minecraft therefore falls back to its vanilla animal resources.

This cleanup covers the custom overrides that were present for axolotls, bees, cats/ocelots, chickens, cows/mooshrooms, dolphins, foxes, frogs, goats, horses/donkeys/mules, llamas, pandas, parrots, pigs, polar bears, rabbits, sheep, sniffers, squid, striders, turtles, and wolves. Hostile mobs, villagers, golems, paintings, GUI art, and unrelated pack content are unchanged.

## Garden chat fonts

Available Garden font IDs:

- `garden:classic` — Minecraft's normal readable font
- `garden:clean` — Minecraft's uniform font
- `garden:medieval` — decorative medieval/fantasy serif
- `garden:storybook` — softer storybook serif
- `garden:smooth` — clean modern sans-serif

The custom font definitions include a `minecraft:default` fallback so unsupported glyphs stay readable.

## Font acknowledgements

These projects were supplied as the visual references for the expanded Garden font selection:

- [Ashen 16x Custom Font](https://www.curseforge.com/minecraft/texture-packs/ashen-16x-custom-font) — medieval/fantasy style reference. Its All Rights Reserved pack files are not redistributed here.
- [Souls RPG Font](https://www.curseforge.com/minecraft/texture-packs/souls-font) — gothic/medieval style reference. The Garden pack uses a separately redistributable serif alternative rather than copying its resource-pack files.
- [Alagard Font](https://www.curseforge.com/minecraft/texture-packs/alagard-font) — pixel-gothic style reference. The All Rights Reserved Minecraft pack implementation is not redistributed here.
- [Der's Smooth Shaded Font](https://www.curseforge.com/minecraft/texture-packs/smooth-shaded-font) — smooth readable style reference. The Garden pack uses Clear Sans under its upstream license rather than copying Der's bitmap assets.

The bundled font alternatives retain their upstream license/copyright notices under `LICENSES/` and inside the deployable ZIP.
