# The Garden SMP Resource Pack

The committed `HerasGardenRP.zip` is the current base pack.

Additional maintainable source files live under `pack-src/`. The resource-pack build workflow overlays those source files onto the base ZIP and uploads a rebuilt pack artifact.

## Garden chat fonts

The first chat font aliases are:

- `garden:classic` — Minecraft's normal readable font
- `garden:clean` — Minecraft's uniform font

These aliases let GardenCosmetics store stable Garden font IDs instead of coupling player preferences to Minecraft's internal font keys.

Future custom bitmap/TTF fonts can replace or extend these aliases without changing the cosmetic entitlement/profile schema.
